# DriveEase Car Rental Management System

CTIS255 Web Technologies 1 project.

## Files
- index.html
- cars.html
- rentals.html
- css/style.css
- js/main.js
- images/

## Required image files
Put these files inside the `images` folder:

- audi-a3.jpg
- bmw-320i.jpg
- mercedes-c200.jpg
- toyota-corolla.jpg
- car-placeholder.jpg

## Features
- Static HTML image cards
- DOM selection and traversal
- createElement, append, innerHTML
- Event listeners
- Event delegation
- Form submit and input/change events
- localStorage for cars, rentals and action logs
- Demo login/signup modal
- Responsive design
